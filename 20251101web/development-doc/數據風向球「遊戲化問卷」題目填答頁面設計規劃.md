# 數據風向球「遊戲化問卷」題目填答頁面設計規劃

作為資深產品經理，我為您規劃了一份完整的遊戲化問卷填答頁面設計，採用日式 RPG 視覺小說風格，提供沉浸式、趣味化的問卷體驗。本設計融合了進度追蹤、故事沉浸感、點數系統與多重結局，確保用戶高度投入[^1][^2][^3][^4]。

***

## 頁面整體架構

### 1. 沉浸式背景層（全螢幕）

**視覺風格**：日式 RPG 插畫背景，參考《勇者鬥惡龍》(Dragon Quest) 與《最終幻想》(Final Fantasy) 的美學風格[^1][^3]。

**場景進度對應**：

- **題目 1-3（起始）**：青蔥村莊晨光，溫暖親切，鼓勵開始冒險
- **題目 4-7（中期）**：古老城堡大廳正午，莊嚴神秘，提升挑戰感
- **題目 8-11（後期）**：神秘森林黃昏，寧靜深邃，引發思考
- **題目 12（結尾）**：魔法塔頂夜幕星空，夢幻光榮，慶祝完成

**視覺效果**：

- 微妙背景動畫（NPC 精靈、樹木搖晃、水面漣漪），增加生動感但不分散注意力
- 溫暖色調營造冒險氛圍，前景、中景、背景分層營造深度
- 高解析度（1920×1080 以上），WebP 格式優化（200-300KB）[^1][^3]

***

### 2. 頂部進度條與控制區（固定）

**位置**：螢幕頂部，高度 80-100px，半透明深色背景搭配毛玻璃效果[^1][^3]。

**元素組成**：

**左側：返回按鈕**

- 圖示：箭頭或「⬅ 返回冒險」文字
- 樣式：透明背景，白色圖示，尺寸 48px（易於點擊）
- 行為：點擊返回問卷選擇頁面，確認是否保存進度

**中央：進度顯示**

- **主標題**：「第 5 / 12 題 - 你的冒險進度」（24-28px 粗體，白色）
- **進度條**：視覺化進度條，顯示完成百分比
    - 背景：半透明深灰，寬度 80-90% 螢幕
    - 填充：品牌主色紫色 \#4F46E5 或漸層色
    - 高度：8-12px
    - 動畫：每答題後平滑過渡（300ms）
    - 百分比或分數顯示在條上方（如「41%」或「5/12」）[^4]

**右側：輔助控制**

- **計時器（可選）**：⏱️ 沙漏圖示 + 「已用時間：2:45」（14px 灰色）
- **音效控制**：🔊 喇叭 Icon，點擊切換背景音樂與音效，預設開啟可靜音

***

### 3. 中央問題卡片區（主視覺）

**位置**：螢幕中上方（20-60% 位置），佔據螢幕寬度 Desktop 60-70%、Tablet 75%、Mobile 90%。

**卡片設計**[^1][^4]：

- **背景**：半透明深色 (rgba(0, 0, 0, 0.5)) 或淡紫色 (rgba(79, 70, 229, 0.1))
- **邊框**：12-16px 圓角，金色邊框 \#D97706 可選（營造奇幻感）
- **內邊距**：32-48px，投影 0 8px 32px rgba(0, 0, 0, 0.3)

**文案結構**：

**主標題（故事敘述風格）**：

- 文案範例：「在古老森林中，你遇見一位神秘的旅人…」
- 字體：28-36px Bold，白色 \#FFFFFF，行高 1.6
- 動畫：新題目時淡入 + 輕微上移

**副描述（故事銜接）**[^4]：

- 文案範例：「他向你提出一個問題…」
- 字體：16-18px Regular，淡金色 \#F5D99A 或淡灰 \#D1D5DB
- 用途：增加沉浸感（可選，支援直接問卷模式無此項）

**心理測驗風格選項**：

- 直接呈現問題「你認為什麼最重要？」，無故事銜接
- 用戶在問卷創建時可選擇遊戲冒險 vs 心理測驗風格

**視覺標籤（可選）**：

- 位置：題目左上角浮動
- 內容：🎮「選擇冒險」、💭「心理測驗」、📊「數據調查」
- 用途：提示題目類型與進度階段

***

### 4. 選項卡片區（核心互動）

**位置**：螢幕中下方到底部（55-90% 位置）。

**響應式佈局**：

- **Desktop**：2×2 網格或 1×4 排列，間距 24px
- **Tablet**：2 列垂直排列，間距 16px
- **Mobile**：單列垂直，全寬 - 24px 邊距，間距 12px

**單個選項卡片**：

**樣式**：

- 背景：半透明奇幻卡片，顏色因選項而異（可選 RGBA 變化）
- 邊框：2-3px 初始為淡金色或品牌次色 \#06B6D4
- 圓角：12-16px
- 內邊距：24-32px
- 最小高度：Desktop 80-120px，Mobile 100px
- 寬度：Full width 減去邊距[^4]

**內容結構**：

1. **選項序號**（左上角）
    - 樣式：A / B / C / D 或 ①②③④
    - 字體：18-24px Bold，金色 \#D97706
    - 圖示或圓形背景強化視覺
2. **選項文字**（主內容）
    - 文案範例：「向旅人伸出友誼之手」
    - 字體：18-20px Regular，白色或高對比色
    - 行高：1.5，對齐：居左
    - 完整顯示在卡片內，無溢出
3. **選項子描述**（RPG 點數反饋，可選）
    - 文案範例：「獲得 +5 友誼值、+3 智慧度」
    - 字體：12-14px，淡綠色 \#86EFAC（正向）或淡紅色 \#FCA5A5（負向）
    - 用途：提示選項後果或獲得點數，增加 RPG 沉浸感
4. **右側裝飾**（視覺平衡）
    - 內容：✨ 光效或選項對應的小圖示
    - 位置：右上角
    - 樣式：淡色，不搶焦點

**互動狀態詳細設計**：


| 狀態 | 視覺變化 | 動畫時長 | 用途 |
| :-- | :-- | :-- | :-- |
| **正常** | 半透明背景，淡邊框，無陰影 | N/A | 初始狀態 |
| **Hover** | 背景亮+15%，邊框變品牌主色，Scale 1.03放大，投影增強 | 200ms ease-out | 引導點擊 |
| **Focus** | 邊框 2-3px 品牌主色，焦點指示 | N/A | 鍵盤導航 |
| **Selected** | 邊框厚 4-5px，背景加深或淡品牌色，出現 ✓ | 150ms cubic-bezier | 確認選擇 |
| **Active** | Scale 0.98 縮小，背景更亮 | 100ms | 點擊反饋 |
| **Submitted** | 禁用狀態（低亮度 50%），鎖定其他選項 | N/A | 防止重選 |
| **Error** | 紅色邊框抖動，紅色提示文案 | 500ms 抖動 + 3 秒消失 | 未填提示 |

**音效與動畫**[^4]：

- 點擊選項：選項卡片閃爍 + 邊框發光 1-2 秒
- 若有點數系統：浮動數字動畫（如「+5 友誼值」上升飄出，300-500ms）
- 清脆確認音（可選，允許靜音）

***

### 5. 操作按鈕區（固定底部）

**位置**：螢幕底部，固定，半透明深色背景搭配毛玻璃效果。

**佈局**：左側「上一題」、右側「下一題」，螢幕寬度 10-15% 外邊距。

**上一題按鈕**：

- 文案：「⬅ 上一題」
- 尺寸：Desktop 140×48px，Mobile 100% 寬
- 樣式：次要按鈕（Outline），邊框品牌次色 \#06B6D4，文字白色
- 行為：返回上一題，保留該題答案
- 禁用：第一題時變灰禁用
- Hover：背景填充淡品牌色，邊框加粗（200ms）

**下一題/提交按鈕**：

- 文案動態：
    - 中途：「下一題 ➜」
    - 最後一題：「完成冒險 ✨」
- 尺寸：Desktop 140×48px，Mobile 100% 寬
- 樣式：主要按鈕（Primary），背景品牌主色 \#4F46E5，文字白色
- 行為：驗證該題是否已答（若必答），通過則進下一題
- 禁用：未選答時禁用（若必答），變灰色
- Hover：背景色加深 -10%，投影增強
- 點擊動畫：按下縮小 Scale 0.98，釋放回復（300ms）

**必填驗證提示**：

- 位置：按鈕上方中央
- 內容：「⚠️ 請選擇一個選項後繼續」（若未答）
- 樣式：14px 紅色 \#EF4444，輕微抖動動畫
- 消失：3 秒後自動淡出

***

### 6. 題目之間的過場動畫

**時序**[^1][^3]：

1. 背景模糊淡出（300ms）
2. 新背景淡入（500ms）
3. 題目卡片從下方滑入（400ms ease-out）
4. 選項卡片逐個淡入（100ms 間隔）

**背景音樂**：可持續播放冒險主題音樂（可選，允許靜音）

***

### 7. 輔助資訊區（可選）

**左下角：角色狀態卡片**（選擇冒險風格時）：

- **位置**：左下角，半透明卡片
- **內容**：
    - ❤️ 生命值：80/100
    - ⭐ 聰慧度：+2
    - 🤝 友誼值：+5
    - 🔥 勇氣值：+1
    - 💎 品格值：+3
- **樣式**：12-14px 灰色，不搶焦點
- **更新**：每答題後實時更新數值動畫（浮動數字飄出，300-500ms）

**右下角：結局追蹤卡片**（可選）：

- **位置**：右下角或題目下方
- **內容**：若問卷設有多重分支，顯示當前選項可能導向的結局方向
- **視覺**：⭐⭐⭐「智者結局」vs ✨✨「浪漫結局」等
- **用途**：增加沉浸感，提示選擇的後果，激勵深思

***

## 色彩與字體系統

**色彩系統**：

- **主色**：\#4F46E5（紫色），用於主要按鈕、邊框
- **次色**：\#06B6D4（青色），用於次要元素
- **背景**：由 RPG 插畫決定（多樣性場景）
- **卡片**：rgba(0, 0, 0, 0.5) 或 rgba(79, 70, 229, 0.1)
- **文字**：\#FFFFFF（白色主文本）、\#F5D99A（金色強調）
- **點數**：\#86EFAC（綠色正向）、\#FCA5A5（紅色負向）
- **提示**：\#EF4444（紅色錯誤）、\#F59E0B（橙色警告）

**字體系統**：

- **標題**：Noto Sans TC Bold 28-36px
- **副標題**：Noto Sans TC Regular 16-18px
- **選項**：Noto Sans TC Regular 18-20px
- **小字**：Noto Sans TC Regular 12-14px
- **行高**：1.5-1.6（易讀性）[^1][^3]

***

## 角色點數與結局系統

**點數類型**（遊戲冒險風格）：

- **❤️ 生命值**：初始 100，健康/和諧選擇加分
- **⭐ 聰慧度**：初始 0，知識/邏輯選擇加分
- **🤝 友誼值**：初始 0，合作/同情選擇加分
- **🔥 勇氣值**：初始 0，冒險/挑戰選擇加分
- **💎 品格值**：初始 0，誠實/正直選擇加分

**結局類型**（多重分支）：

- **智者結局**：聰慧度 > 70，其他均衡
- **浪漫結局**：友誼值 > 70，品格值 > 60
- **英雄結局**：勇氣值 > 70，生命值 > 70
- **學者結局**：聰慧度 > 60，勇氣值 < 30
- **哲人結局**：全項 > 50 且高度均衡

**結局呈現**：獨白敘述 + 插畫 + 背景音樂 + 個性化報告

| 裝置 | Desktop (>1024px) | Tablet (768-1024px) | Mobile (<768px) |
| :-- | :-- | :-- | :-- |
| **背景** | 全尺寸高解析度 | 略微縮放 | 裁切/縮放，可降低品質 |
| **進度條** | 80% 寬 | 85% 寬 | 90% 寬，14px 字體 |
| **選項** | 2×2 網格 | 2 列垂直 | 單列垂直 |
| **卡片寬** | 60-70% | 75% | 90% |
| **按鈕** | 140×48px | 140×44px | 100% × 56px |

## 無障礙設計與效能

**無障礙**：

- 鍵盤導航：Tab 切換選項，Enter 確認，↑↓ 上下導航
- 螢幕閱讀器：正確語義 HTML，按鈕標籤清晰
- 色彩對比：文字與背景對比度 ≥ 4.5:1（WCAG AA）[^3]
- 焦點指示：明確焦點邊框（金色或品牌色）

**效能**[^1][^3]：

- 背景圖：WebP 格式，200-300KB，預加載
- 動畫：使用 CSS 動畫 (GPU 加速)，transform + opacity
- 首屏載入：LCP < 2.5s，FID < 100ms
- 音效：MP3/OGG，預加載可選，提供靜音選項
